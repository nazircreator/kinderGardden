# 🌱 Little Sprouts — A Gentle Garden

Уютная пиксельная игра-симулятор сада на **React + TypeScript + Canvas**.
Вы — садовник (keeper), а в саду живут **растения-малыши**: они ходят, бегают,
плачут, капризничают, засыпают и растут. Их нужно кормить, поить, обнимать,
играть с ними и — главное — **разговаривать**, поддерживая их спокойствие и
уверенность в себе.

Стиль — пиксель-арт в духе Stardew Valley: всё нарисовано кодом на `<canvas>`,
без внешних картинок.

---

## 🚀 Как запустить

Нужен **Node.js 20+** (проверено на 24).

```bash
# 1. Перейти в папку проекта
cd "Программирование/kinderGarden"

# 2. Установить зависимости (один раз)
npm install

# 3. Запустить игру в режиме разработки
npm run dev
```

После этого откройте в браузере адрес, который выведет Vite:

```
http://localhost:5178/
```

Сборка для продакшена:

```bash
npm run build     # соберёт в папку dist/
npm run preview   # локальный предпросмотр сборки → http://localhost:5179/
```

Проверка типов отдельно:

```bash
npm run typecheck
```

> Если `npm install` падает с ошибкой `EROFS` (недоступен глобальный кэш npm),
> используйте локальный кэш:
> `npm install --cache ./.npm-cache`

## 🎮 Управление

| Клавиши | Действие |
| --- | --- |
| `WASD` / стрелки | ходить |
| `Shift` | бежать |
| `E` или клик по малышу | открыть карточку ухода |
| `T` | **поговорить** (главный инструмент поддержки) |
| `F` / `R` / `C` | покормить / полить / обнять |
| `P` / `G` / `Y` | играть / петь / читать сказку |
| `B` | дыхательная пауза вместе с садом |
| `N` | уложить спать / разбудить |
| `J` / `M` / `K` | журнал / карта сада / магазин |
| `L` | Летний павильон (аркада с мини-играми) |
| `Esc` | закрыть окно |

На телефоне и планшете появляются экранный джойстик, кнопки действий и нижнее
меню.

## 🌿 Что в игре

**Четыре потребности** у каждого малыша: еда, вода, отдых и комфорт. Если о них
долго не заботиться — малыш начинает грустить и **плакать**, и вам приходит
уведомление, в какой части сада его нужно поддержать.

**Разговоры.** Три варианта ответа — выслушать, порадоваться вместе, просто
посидеть рядом. Каждый разговор растит три показателя:

- **Heart** — привязанность;
- **Calm** — внутреннее спокойствие;
- **Trust** — доверие.

Именно разговоры и спокойствие позволяют малышу **расти**, а не только еда.

**Рост.** Четыре стадии: Seedling → Sprout → Budling → **Bloomed**.
Цветение даёт семена и гармонию.

**Гармония сада** складывается из украшений, привязанности и цветения. За
семена и гармонию **открываются новые части сада**:

1. Heartmeadow — дом, колодец, домик (доступно сразу)
2. Dewdrop Pond — пруд с лилиями
3. Sunroot Terrace — солнечные грядки
4. Whisper Hollow — сумрак, грибы и светящиеся кристаллы
5. Moonlit Orchard — цветущие ряды
6. **Lantern Arcade** — павильон с гирляндами и четырьмя мини-играми

**Украшения.** В магазине 18 предметов (фонари, скамейки, качели, арки,
перголы, кусты, деревья…). Покупайте и расставляйте их в саду — каждое даёт
гармонию и делает место безопаснее.

**Время и дни.** День идёт с 6:00 до 2:00, есть рассвет, закат и ночь с
фонарями. Ночью можно спать в домике — начнётся новый день со своей погодой
(солнце, облака, дождь) и новыми заданиями.

**История.** 6 глав с письмами от Старой Ивы. Главы открываются по мере заботы,
а письмо с наградой нужно прочитать в журнале.

**🎪 Lantern Arcade и мини-игры.** За лунной рощей открывается маленький
праздник: полосатый шатёр, гирлянды, призовой стенд и четыре игры. В каждой можно
заработать семена и ягоды:

- **Berry Catch** — ловите падающие ягоды корзинкой, уклоняйтесь от камней (45 сек).
- **Memory Garden** — переворачивайте листья и находите пары.
- **Firefly Glow** — ловите светлячков, пока они не погасли.
- **Melody Blooms** — повторяйте песенку цветов, с каждым раундом на ноту длиннее.

Рекорды сохраняются, а за новый рекорд даётся бонус. Открыть аркаду можно кнопкой
`L`, кнопкой с шатром в шапке или подойдя к стенду и нажав `E`.

**🎃 Nerdy — пассивное растение.** В аркаде живёт Нерди: pumpkin-малыш в
круглых очках, который ведёт таблицу рекордов и волнуется о гирляндах. Он **не ходит
и не плачет** — он укоренён на месте, как настоящее растение, — но о нём всё равно
нужно заботиться: он растёт, набирает heart/calm/trust и может зацвести. В его
карточке ухода есть отдельная плашка «ARCADE HOST».

**Новые малыши** приходят в сад на 2, 3, 5, 7, 10, 13 и 16 день.

**Погода и дождь** поливают растения бесплатно, а ночью сад затихает.

**Звук** полностью синтезируется кодом: медленная музыкальная шкатулка и мягкие
звуки (без аудиофайлов).

## 🖱 Дружелюбный интерфейс

- **Панель быстрой заботы** — подойдите к малышу, и внизу появится ряд кнопок
  (Покормить, Полить, Обнять, **Поговорить**, Играть). Кнопки подсвечиваются
  красным, когда малыш особенно нуждается.
- **Подсказки при наведении** — наведите курсор на кнопку или предмет, чтобы
  прочитать, что он делает.
- **Плашка главы и дневные задания** — всегда видны в правой панели.
- **Карта сада** с превью каждой зоны и понятной ценой разблокировки.
- **Экран аркады** с рекордами и правилами для каждой игры.
- Всё адаптировано под телефон: джойстик, кнопки действий и нижнее меню.

## 💚 Про заботу и психику

Игра сознательно сделана **без проигрыша**. Нельзя «провалить» сад: можно только
замедлиться. Если малыш плачет — это не ошибка игрока, а приглашение побыть
рядом. Поэтому:

- есть режим **Gentle pacing** — потребности падают на 40% медленнее;
- успокоение даёт «период тишины», чтобы одна и та же боль не вызывала слёзы
  бесконечно;
- ответы на разговоры никогда не блокируют управление.

## 🗂 Структура проекта

```
src/
  main.tsx              точка входа
  App.tsx               весь UI на React
  styles.css            оформление в пиксельном стиле
  game/
    types.ts            типы данных
    content.ts          мир: зоны, реплики, предметы, главы, задания
    sprites.ts          пиксель-арт: садовник, малыши, объекты
    world.ts            генерация карты, коллизии, вода, лес, свет
    state.ts            сохранение, баланс, гармония, прогресс
    engine.ts           игровой цикл, взаимодействия, погода, частицы
    dialogue.ts         реплики персонажей, сказки, обучение
    audio.ts            процедурная музыка и звуки
  ui/
    Portrait.tsx        портреты малышей, полоски потребностей
    icons.tsx           пиксельные иконки интерфейса
    art.tsx             превью предметов, миниатюры зон, погода
    arcade.tsx          четыре мини-игры и экран аркады
tools/                  скрипты автотестов (puppeteer) — не нужны для игры
```

Прогресс сохраняется в `localStorage` браузера. Ничего не отправляется в сеть.

## 🧪 Автотесты (необязательно)

В папке `tools/` лежат скрипты, которыми проверялась игра в реальном браузере
(нужен запущенный `npm run dev` и установленный Chrome):

```bash
node tools/gameplay.mjs   # полный игровой цикл, дни, сохранения
node tools/ui.mjs         # кнопки, разговоры, успокоение, магазин
node tools/chapter.mjs    # главы, письма, награды
node tools/balance.mjs    # скорость падения потребностей
node tools/arcade.mjs     # доступность аркады и стендов
node tools/verify3.mjs    # Nerdy, быстрая забота, награды аркады
node tools/keys2.mjs      # горячие клавиши и Escape
node tools/mobile3.mjs    # раскладка на телефоне и планшете
```
